## About

I'm a data/infrastructure engineer focused on the systems that make data usable
and governable at scale — data cataloging and access control, lakehouse
infrastructure, and the developer tooling around it. Most of my work lives at the
intersection of **AWS data services**, **infrastructure-as-code**, and **platform
engineering**, and I care a lot about making that infrastructure reproducible,
auditable, and easy for other engineers to build on.

## What I work on

**Data governance & access control**
- Data cataloging and fine-grained access with **AWS Lake Formation** and the **Glue Data Catalog**
- Migrating hybrid Glue tables to Lake-Formation-managed permissions and modeling grant hierarchies
- Data-mesh style workflows on **Amazon DataZone / SageMaker Unified Studio** — projects, subscriptions, and programmatic asset access

**Infrastructure as code**
- **Terraform** modules for Lake Formation permissions, Glue Data Catalog views, and reproducible platform infra
- Debugging provider behavior (in-place vs. destroy/recreate) to keep grants and state stable across updates

**Query & data engineering**
- Interactive analytics with **Athena** (Presto/Trino views over governed tables)
- ETL and transformation with **Glue** and **PySpark**

**Platform tooling & auth**
- **MCP (Model Context Protocol)** servers exposing internal data services to AI tooling
- Enterprise auth flows — **OIDC / SAML**, Authorization Code Flow with PKCE, JWT/JWKS validation
- **IAM**, **STS** (scoped role assumption / source identity), **EventBridge + Lambda** automation
